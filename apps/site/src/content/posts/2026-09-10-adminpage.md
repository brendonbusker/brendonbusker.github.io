<p>I kinda wanted to write a post about what I call my "admin page". No one else can view this but me (knock on wood) and it's where I publish these blog posts, update my resume, and add new projects that I've been working on.</p><p>A few really good friends of mine recommended some great ways to make edits to my website but after polishing up my admin page I kinda fell in love with how custom I can make it.</p><p>The home page:</p><img src="/uploads/posts/adminpage/1789090872119-5a60b2ad-390d-4894-955b-bdd364d7ed2f.webp" alt="homepage" data-layout="block" /><p>This is my landing page, it tells me at a glance what I've been working on and gives me a few quick access buttons. Writing this now is showing me actually I need to fix the "latest post" section because that is so not correct.</p><p>The Blog page:</p><img src="/uploads/posts/adminpage/1789091029924-34f5d73b-2878-4f19-b810-da11ef6b467a.webp" alt="blogpage" data-layout="block" /><p>This is where I am literally right now. What's cool about this page is I built the page editor to practically mimic what you would expect to see in Microsoft Word or Google Docs, so everything feels natural. Here I can see old posts, make new ones and even edit my "page introduction" which is really just the big title that says "The blog." on my website.</p><p>The projects page:</p><img src="/uploads/posts/adminpage/1789091215483-e09e14c2-ecc8-41e2-9182-062c420bdde0.webp" alt="projectspage" data-layout="block" /><p>Here is where I manage all the projects that get posted to my website. This is essentially the card designer that builds out what you see on the actual projects page. I can edit literally everything that goes into it while keeping the same style as the other published projects.</p><p>The resume page:</p><img src="/uploads/posts/adminpage/1789091396038-18acaff0-6b97-478d-8927-e17cd9bdbc71.webp" alt="resumepage" data-layout="block" /><p>This page is really cool and it happens to be the most recently updated page. So for those of you that know, ResuMake is no longer being supported which really upset when I heard about it because that was the tool I had been using for a long time to build my resume. Here I've kinda rebuilt it, though it isn't quite as good yet as it only will generate one distinct style/format. Nevertheless, it does the job great for now and allows me to host my resume online and make edits at ease. Obviously the screenshot is cutoff, but it goes down quite a long way and includes lots of features.</p><p>The site page:</p><img alt="homepage intro" data-layout="block" src="/uploads/posts/adminpage/1789091621292-29f2c693-879a-4d78-8272-09165673da3e.webp" /><p>And here's the last piece, my homepage intro editor. This is quite simple, but as you can see it has everything that you see on my actual landing page for the personal website. </p><p>So that's it, that's pretty much the entirety of my admin page. Everything that gets published on my website comes through here, which I think is pretty cool because every time I think of something new I want to add I can just do it on my own admin page. </p>
